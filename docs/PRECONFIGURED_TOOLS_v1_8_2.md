# Preconfigured Tools — v1.8.2

タスクバー固定済みショートカットから確認した、インストール版EXEを使用します。

## Tape Reel Designer 3D

- Launch type: `exe`
- Target: `%LOCALAPPDATA%\Programs\Tape Reel Designer 3D\TapeReelDesigner3D.exe`
- Working directory: `%LOCALAPPDATA%\Programs\Tape Reel Designer 3D`
- Enabled: `true`
- 対応する固定ショートカット: `Tape Reel Designer 3D (2)`

## 周期構造テープ成形デザイナ

- Launch type: `exe`
- Target: `%LOCALAPPDATA%\Programs\TapeDesigner\TapeDesigner.exe`
- Working directory: `%LOCALAPPDATA%\Programs\TapeDesigner`
- Enabled: `true`
- 対応する固定ショートカット: `周期構造テープ成形デザイナ`

portable/dist版ではなく、タスクバー固定先と同じEXEを起動するため、別アイコンとして開く問題を避けます。
