# Page Guide

## Home
Daily dashboard. Shows recent tools, projects, and pinned notes.

## Tools
Application registry and launcher. Future applications are added here without rebuilding NEXUS.

## Project Atlas
Groups tools by research project and visualizes the current tool set for the selected project.

## Research Notes
Persistent research notes with edit, delete, pin, and project linkage.

## App Guide
Explains the purpose of every active page.

## Settings
Visual preferences, running processes, launch history, user data, and backups.

Shared and Team were removed from the main navigation because they were placeholders without real connected data.
