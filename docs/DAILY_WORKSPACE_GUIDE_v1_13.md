# Daily Research Workspace Guide

## Home

`WORKSPACE PULSE`には、起動中ツール、最近使ったツール、選択中プロジェクト、注意事項が表示されます。

## 横断検索

`Ctrl + K`で、ツール、プロジェクト、メモ、登録資料を検索できます。

## Project Atlas

プロジェクトへ以下を関連付けられます。

- ツール
- ファイル
- フォルダー
- URL
- 解析結果・成果物
- Research Notes

資料は元の場所へリンクされ、NEXUS内へ複製されません。

## パス切れ

移動・削除された資料は`ATTENTION`に表示されます。元ファイルを戻すか、登録を解除してください。
