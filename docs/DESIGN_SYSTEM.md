# Design System — Street Research Hub

## 採用テーマ

ステンシル、ストリートアート、紙、スプレー、付箋を、研究ツール管理UIとして成立する範囲に整理して使う。

## 原則

1. 研究ツールは同じ形の無個性なカードにしない。
2. 操作対象は紙面から浮き、ホバー時に物理的に反応する。
3. マゼンタ、シアン、黄はカテゴリ・選択・注目に限定する。
4. 本文は読みやすいシステムフォント、見出しは太いステンシル調。
5. 汚れは装飾であり、文字や操作を邪魔しない。
6. 動きは拡大・発光だけでなく、内容を説明する方向へ発展させる。

## 次の3D化対象

- Tape Reel Designer: リールの短い回転、テープ送り
- Periodic Tape Designer: 周期テープの送りとローラ開閉
- Radia Studio: 磁石配列と磁場線の立上がり
- Model Interpreter: ワイヤーフレームから立体への変換
- Paper Translator: ページ送りと翻訳レイヤー
- WS Control: モータ、ステージ、インジケータ
