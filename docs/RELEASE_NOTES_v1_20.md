# NEXUS CORE v1.20.0 リリースノート

NEXUS COREは、ローカルの研究ツールを登録・起動し、研究プロジェクト、メモ、既存のファイルやフォルダーを一か所から参照するWindows用デスクトップアプリです。

## 基本的な使い方

1. **TOOLS**でアプリを登録・起動する。
2. **PROJECT ATLAS**でプロジェクトへツールや資料を関連付ける。
3. **RESEARCH NOTES**で短い研究メモを残す。
4. **HOME**で最近使ったツール、実行中ツール、進捗、注意事項を確認する。
5. **SETTINGS**で起動映像、実行中プロセス、バックアップ、復元を管理する。

## 起動映像

- **FULL**：完全版を再生
- **QUICK**：日常利用向けの短縮版
- **OFF**：映像を再生せずHomeへ移動

初回起動ではFULLを使用し、設定を固定していない場合は2回目以降QUICKを使用します。

## データ保護

ユーザーデータは`%LOCALAPPDATA%\NexusCoreStreetResearchHub`へ保存され、インストール済みEXEとは分離されています。更新時にはユーザーデータとカスタム画像をバックアップし、直前のEXEもロールバック用に保持します。

## 初期登録済みツール

配布時の初期設定には、現在のPCで確認された以下のインストール先を含みます。

- Tape Reel Designer 3D
- Periodic Tape Designer

インストール場所が変わった場合は、TOOLSのパス修復または設定編集から変更できます。
