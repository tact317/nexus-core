# NEXUS CORE Street Research Hub v1.6

## Hero Cleanup & Painted Intro

### Painted startup canvas
- Added a full-screen startup canvas built with SVG, CSS masks and live HTML controls.
- The intro paints black, pink and cyan strokes in sequence, reveals the title and stencil figures, then attaches three note cards.
- `START`, `SKIP`, Enter, Space and Escape all dismiss the intro safely.
- The intro respects reduced-motion preferences.

### Hero composition
- Replaced the oversized complete pink circle with a partial brush arc.
- Replaced CSS border fragments and floating arrowheads with a single SVG coordinate system.
- Limited the visual flow to three explicit routes: Explore to center, center to Connect, and center to Create.
- Enlarged `MAKE / TEST / LEARN`, increased line spacing and removed the dashed secondary circle.
- Moved the three live sticky-note buttons outside the brush arc.
- Kept title and stencil figures as non-interactive image assets; all controls remain live HTML/CSS/JS.

### Scope
- No real application launching is included.
- Tools, Atlas, Notes, search, settings, drag ordering and drawers remain unchanged.
