# UI Freeze Checklist — v1.7

実機確認後、次の項目に問題がなければデザインと操作基盤を凍結し、機能実装へ進みます。

## Start

- [ ] 描画演出が長すぎない
- [ ] START、SKIP、Enter、Space、Escapeが動作する
- [ ] Settingsでイントロを無効化すると次回は直接Homeが開く
- [ ] Settingsの再生ボタンでイントロへ戻れる

## Home

- [ ] 日本語見出し、人物、中央文字、付箋が重ならない
- [ ] 中央文字をクリックすると3種類の文言が切り替わる
- [ ] EXPLORE、CONNECT、CREATEの見た目とクリック領域が一致する
- [ ] Quick Launch、Tools、Projects、Notesの情報が読みやすい

## Tools

- [ ] 検索とカテゴリ絞り込みが動作する
- [ ] 件数が検索結果と一致する
- [ ] 自由配置時だけドラッグできる
- [ ] 名前順、カテゴリ順、更新順では誤ドラッグしない
- [ ] ドラッグ終了直後に詳細が誤って開かない
- [ ] 詳細ドロワーのボタンや最近使ったファイルが重ならない

## Project Atlas

- [ ] ノードと線が移動・ズーム中も一致する
- [ ] 背景ドラッグとノード選択が競合しない
- [ ] RESET、＋、−が動作する
- [ ] 凡例が画面幅に応じて折り返す

## Research Notes

- [ ] すべて、ピン留め、最近の切替が動作する
- [ ] 件数が表示内容と一致する
- [ ] ピンボタンとカード選択が競合しない
- [ ] 本文とフッターが重ならない
