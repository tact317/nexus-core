# Changelog v1.16.0

- 起動映像を`FRAGMENT ASSEMBLY`から`CINEMATIC WALL / ACCESS GATE`へ全面変更。
- 3枚の新規壁面アートを独立ショットとして採用。
- 9.766667秒、1920×1080、30fps、H.264 High、約20Mbpsへ高画質化。
- 48kHzステレオAACの独自サウンドデザインを追加。
- 初期ミュートと`SOUND OFF / SOUND ON`切り替えを追加。
- 映像上の工程名、状態ボックス、色付き進行バーを撤去。
- 動画終了後の遷移を中央圧縮から左右ゲート開放へ変更。
- 手動スキップ専用の短いフェード遷移を追加。
- Enter、Space、Esc、`SKIP`のスキップ経路を維持。
- 自動再生拒否時だけ`PLAY FILM`を表示。
- モーション低減時は動画を省略して短時間でHomeへ移行。
- アプリバージョンを`1.16.0`へ更新。
