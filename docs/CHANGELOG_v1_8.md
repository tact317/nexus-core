# NEXUS CORE Street Research Hub v1.8

## Function Foundation

- Python標準ライブラリだけで動くローカルLaunch Bridgeを追加
- `data/tools.json`によるツールmanifest管理を追加
- EXE、Python、PowerShell、BAT、URL、Folder起動へ対応
- Windows用ファイル／フォルダー選択ダイアログを追加
- ツール詳細へ起動状態、起動設定、履歴を追加
- Tool Registry編集フォームを追加
- SettingsへLaunch Bridge状態と登録数を追加
- 起動成功、失敗、PID、ログ位置を履歴へ保存
- Homeのツール表示を最近の起動履歴へ連動
- Project AtlasのプロジェクトへツールIDを保存
- JSON保存時の`.bak`自動生成を追加

## UI Freeze Policy

v1.7のデザインコンセプトと基本レイアウトは維持しています。v1.8で加えたUIは、Tool Registry、起動状態、履歴表示のみです。
