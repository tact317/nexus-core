# Changelog v1.17.0

- 起動直後の白画面を抑える初期描画CSSと暗色WebView背景を追加。
- 起動イントロをFULL / QUICK / OFFの3モードへ変更。
- 初回FULL、2回目以降QUICKの既定動作を追加。
- QUICK再生を動画終盤約3.9秒へ設定。
- Settingsへイントロモード選択UIを追加。
- 動画終了後のゲート遷移を0.72秒へ調整。
- 動画の読み込み失敗、停止、待機超過時の安全終了を追加。
- FULL / QUICKの再生区間に対応する進捗計算へ変更。
- Windows二重起動防止用の名前付きMutexを追加。
- インストール時のデータ自動バックアップと旧EXE保持を追加。
- `rollback_desktop.ps1`を追加。
- アプリバージョンを1.17.0へ更新。
