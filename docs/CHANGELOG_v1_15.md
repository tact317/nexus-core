# Changelog v1.15.0

## Opening film

- v1.14の起動動画、ポスター、生成スクリプトを削除。
- 完全新規の`FRAGMENT ASSEMBLY`映像を追加。
- 8.4秒、1920×1080、30fps、H.264、無音で生成。
- Homeの人物、ヒーロー、タイトル画像、構図、配色を不使用。
- 起動専用の研究断片7種を手続き生成。
- 起動専用の`NEXUS / CORE`分割タイポグラフィを追加。
- ポスター、最終フレーム、6コマストーリーボードを追加。

## Runtime integration

- 動画終了後に自動でHomeへ移行。
- Enter / Space / Esc / Skipボタンへ対応。
- 自動再生拒否時の`PLAY FILM`フォールバックを追加。
- 動画エラー時の自動バイパスを追加。
- モーション低減設定時の短縮遷移を追加。
- 進捗バーと5段階ステータス表示を追加。
- 最終フレームの中央線と連動する`ACCESS CUT`圧縮遷移を追加。

## Versioning and documentation

- アプリバージョンを`1.15.0`へ更新。
- READMEをv1.15仕様へ全面更新。
- アートディレクション、変更一覧、QA報告を追加。
