# NEXUS CORE Street Research Hub v1.7

## UI Final Polish & QA

v1.6のデザイン基準を維持したまま、UI凍結前の細部調整を行った版です。

### Home

- 中央メッセージの説明文を実UIとして追加
- 中央文字、ブラシアーク、矢印、付箋の階層を再調整
- ツールカード、Project Atlas、Research Notesの本文省略と余白を統一

### Start

- START／SKIPにキーボード案内を追加
- Settingsから起動イントロの表示・非表示を保存可能
- Settingsからイントロを再生可能

### Tools

- 検索結果件数を表示
- 自由配置、名前順、カテゴリ順、更新順を追加
- 自由配置以外ではドラッグを無効化し、誤操作を防止
- ドラッグ後の誤クリックを抑止
- ドラッググリップとドロップ先表示を明確化

### Project Atlas

- 接続線の凡例を追加
- ツールバーを狭い画面でも折り返す構造へ変更
- ノードの文字組みとタッチ操作を調整

### Research Notes

- すべて、ピン留め、最近の表示切替を追加
- 件数表示を追加
- ピン操作をカード上の実ボタンへ分離
- カード本文とフッターが重ならない構造へ変更

### Settings / Drawer

- 起動イントロ設定と再生ボタンを追加
- ツール詳細ドロワーのHTML階層を修正
- 操作ボタンのクリック領域を統一
