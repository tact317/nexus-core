# 既知の制限 — v1.20.0

- 現在の正式対応OSはWindowsです。
- ローカルツールのパスはPC固有です。移動・再インストール後はパス修復が必要な場合があります。
- 既存ウィンドウの前面表示は、起動先アプリのプロセス構成やウィンドウ実装に左右されます。
- 起動映像をローカル同梱しているため、配布ZIPとEXEの容量が増えます。
- pywebviewを利用できない場合だけブラウザ型の予備表示へ切り替わります。
- Project Atlasへ登録したファイルやフォルダーは元の場所を参照し、NEXUS内へコピーしません。
- 未完成ツールは一覧へ残せますが、起動設定を有効にするまでは起動できません。
