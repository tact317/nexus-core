# Function Implementation Roadmap

## Phase 1 — Manifest

ツール名、説明、カテゴリ、画像、実行方式、実行パス、引数、作業ディレクトリをJSONで管理する。

## Phase 2 — Local Launch Bridge

ブラウザUIからローカルサービスへ起動要求を送り、成功、失敗、PID、ログ位置を返す。

## Phase 3 — Workspace data

プロジェクト、ノート、成果物、最近使用したツールを実データへ接続する。

## Phase 4 — Portable package

パスの環境差を吸収し、別PCでも設定を移行できるバックアップ／復元を追加する。
