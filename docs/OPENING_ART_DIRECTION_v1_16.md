# Opening Art Direction v1.16 — CINEMATIC WALL / ACCESS GATE

## 目的

v1.15で指摘された「要素が重なる」「情報を足しすぎて安く見える」という問題を解消し、起動時だけの短編映像として成立させる。

Home画面の人物、タイトル画像、ピンク／シアンのグラフィック、Home用フォント処理は使用しない。起動映像は別の撮影作品として開始し、最後の物理的な開口だけをHomeへの接続に使う。

## 採用方針

名称：`CINEMATIC WALL / ACCESS GATE`

3枚の高精細な壁面アートを、同一画面上に重ねず、別ショットとして編集する。

1. `TRAVERSE`
   - 余白のあるコンクリートから研究資料へ横移動する導入
   - 観客へ空間と素材のスケールを先に理解させる

2. `FIELD`
   - 密度の高い研究壁面へ切り替える
   - カードを個別に飛ばさず、完成した壁面をカメラで観察する

3. `COIL INSERT`
   - コイル図面へ短く寄る
   - 研究内容を抽象記号だけで終わらせない

4. `SIGNAL INSERT`
   - 波形へ切り返す
   - 編集のリズムを作り、静止画の連続ズーム感を消す

5. `ACCESS PULLBACK`
   - 縦スリット付近から引き、起動専用タイトルと全体構図を確立
   - 最終フレームを左右の壁面パネルとして保持

6. `ACCESS GATE`
   - 左右の壁面が縦スリットから開く
   - 背後で既に初期化済みの実Homeを露出

## 視覚原則

- 大きな工程ラベル、登録番号、状態表示を動画上へ重ねない
- 色付きプログレスバー、発光、パーティクルを使用しない
- UIは左下の音声、右下のスキップ、最下部2pxの進行線だけ
- コントラストと粒状感は控えめにし、紙と壁のテクスチャを優先
- Homeの静止画を動画へ埋め込まない

## 音設計

- 低い室内の空気音
- 編集点に同期する短い紙・空気のトランジェント
- 密度の高い壁面ショットに薄いグラファイト音
- 縦スリットへの切り替えに低域インパクト
- 予告編的な過剰な大音量マスタリングは避ける

ブラウザの自動再生条件を守るため、初期状態はミュート。ユーザー操作で音声を有効化できる。

## Homeへの接続

動画の最終ポスターとCSSゲートは同一画像を使用する。動画終了時に映像をポスターへ置換し、スリット位置`62.85%`を境界として左右へ開く。

手動スキップでは最終ポスターへ飛ばさず、短いフェードでHomeへ移行する。これにより、開始直後のスキップで不自然な最終構図が一瞬表示される問題を避ける。
